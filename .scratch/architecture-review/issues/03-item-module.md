# 03: 道具 module

**What to build:** 防護罩、火箭、櫻桃三種道具的身分不再以整數 1／2／3 散落各處。木箱抽選（一般防護罩／火箭各半；最後一名 50% 櫻桃）、使用效果、顯示名稱、車名後標籤（[盾]／[箭]／[櫻]）、狀態欄文字集中在一個道具 module。新增或調整一種道具只需改這一處。

**Blocked by:** 02（櫻桃計時已屬於車輛生死週期）

**Status:** ready-for-agent

- [ ] 道具名稱、標籤、狀態文字與使用效果只在道具 module 中定義
- [ ] 木箱欄位的說明正確描述「隨機木箱」，不再寫著過時的固定道具
- [ ] 抽選機率可直接驗證：最後一名約 50% 櫻桃、領先者 0% 櫻桃
- [ ] Play Mode：撿木箱、使用三種道具、火箭池滿時保留道具、提示文字與修改前相同
- [ ] 重新編譯成功，Console 零錯誤、零警告

# 02: 車輛生死週期 module

**What to build:** 一台車的「撞毀 → 打滑飛出 → 隱藏 → 3 秒後重生（保留扣分後分數、2 秒保護）」與「計時淘汰 → 打滑飛出 → 永久退場」由同一個 deep module 負責。車輛自己持有櫻桃剩餘時間、碰碰車滑行、打滑飛出、淘汰名次等狀態，不再由比賽主程式以每車平行陣列保存；撞毀、淘汰、重生不再各自手動清空欄位。之後調整生死規則只需改一處。

**Blocked by:** 01

**Status:** done (architecture-review-01)

- [x] 比賽主程式不再有以車輛索引存放的每車狀態陣列（寫死長度 4 的陣列消失）
- [x] 撞毀、淘汰、重生、給予櫻桃、施加滑行各自透過一個呼叫完成，呼叫端不需知道要清哪些欄位
- [x] 現有驗證腳本（撞毀、打滑飛出、櫻桃、碰碰車）改為不使用反射即可設定櫻桃狀態與檢查結果，且全部通過
- [x] Play Mode：一般撞毀與計時淘汰的打滑飛出、3 秒重生、2 秒保護閃爍、排行榜淘汰名次與修改前相同

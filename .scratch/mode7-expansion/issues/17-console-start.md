# 17: 主機化：拿掉投幣，按 START 開始

**What to build:** 遊戲改成主機遊戲，不再是投幣街機。「街機模式」改名「一般模式」，不再有硬幣。

- **START**：鍵盤空白鍵、手把 Start 鍵。
- **標題（一般模式）**：背景照樣是 AI 示範，閃爍「按 START 開始」。按 START 跳出「1 人／2 人」選單，左右鍵選，再按 START 開始；Esc／手把 B 關閉選單。
- **標題（挑戰模式）**：START 開始選到的挑戰；未解鎖時 START 花金幣解鎖。
- **投幣繼續 → 免費繼續**：40／80 秒被淘汰的真人，每局**限 1 次**、10 秒內按 START 免費復活（P1：空白鍵／第 1 支手把 Start；P2：數字鍵 Enter／第 2 支手把 Start），復活規則不變；已用過就直接出局。
- **結算畫面**：不再自動回標題；START 用同樣設定再玩一局（挑戰則重試），Esc／手把 B 回標題（挑戰回列表）。
- **移除**：5 投幣、手把 Select 投幣、1／2 開局、左 Ctrl 開局（左 Ctrl 仍是 P1 道具鍵），以及所有投幣文字。
- 不變：左右鍵切換一般／挑戰、G 車庫、T 手排／自排、金幣。

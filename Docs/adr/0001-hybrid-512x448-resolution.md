# Mode 7 版採用 512×448 混合解析度

Mode 7 主線的輸出為 512×448，但場景美術一律以 2×2 粗像素繪製（看起來等同 SFC 256×224），只有文字與 HUD 使用 512×448 原生像素；顯示以整數 2 倍（1024×896）為主。原因是使用者要 SFC 的畫面感，又需要比 320×320 更多的排版空間（8 台車排行榜、2P 分割、11px 中文字）。這也是 SFC 遊戲以高解析度畫文字的做法。

## Considered Options

- **256×224**：最道地，但比 320×320 更擠，11px 中文字一行只能放約 23 字，2P 每人只剩 256×112。
- **512×478**：PAL 隔行掃描的高解析度，SFC 的精靈圖與 Mode 7 都不能用這個解析度，畫面會像 PC 遊戲；2 倍顯示 1024×956 在 1080p 螢幕放不下；478 與 224 的美術尺寸對不上。
- **維持 320×320 只放大**：改動最少，但不是 SFC 比例，也沒有多出排版空間。

## Consequences

美術以 256×224 的尺度設計，再放大 2 倍。不要把場景美術改成原生 512×448 的細像素，否則會失去 SFC 感；也不要把文字改成 2 倍粗像素，否則排版空間會跟 256×224 一樣不夠。
